# PWD Application System - Replit Deployment

## 🚀 Quick Deploy to Replit

### Step 1: Create Replit Account
1. Go to [replit.com](https://replit.com)
2. Sign up for free account
3. No credit card required!

### Step 2: Create New Repl
1. Click "Create Repl"
2. Choose "Docker" as template
3. Name your project (e.g., "pwd-application-system")
4. Click "Create"

### Step 3: Upload Your Code
1. In Replit, click the 3 dots menu → "Upload folder"
2. Select your entire `PWD-Application-System` folder
3. Wait for upload to complete

### Step 4: Run the Application
1. Click the green "Run" button
2. Wait for Docker containers to build and start
3. Your app will be available at the Replit URL

### Step 5: Database Setup
If needed, run the setup script:
```bash
./setup.sh
```

## 📋 What's Included
- ✅ Docker configuration optimized for Replit
- ✅ PostgreSQL database
- ✅ PHP 8.2 with Apache
- ✅ Automatic database initialization
- ✅ Public URL for testing

## 🔧 Troubleshooting
- If containers fail to start, check the Replit logs
- Database connection issues? Wait for PostgreSQL to fully initialize
- Need to restart? Click "Stop" then "Run" again
